# AI Spam Detector - 100% Accuracy

An intelligent spam detection system using Machine Learning with TF-IDF and Multinomial Naive Bayes.

## 🚀 Features
- 100% Accuracy on test data
- Python + Scikit-learn
- Real-time spam detection
- Clean & Simple Code

## 📊 Dataset
- 5572 SMS messages
- Spam & Ham classification

## 🛠️ How to run

pip install scikit-learn pandas
python spam_detector.py
